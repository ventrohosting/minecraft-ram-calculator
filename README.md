# Minecraft Server RAM-Rechner

Berechne den RAM-Bedarf deines Minecraft-Servers nach Spielerzahl, Serverart und Weltgröße: kostenlos, mit nachvollziehbarer Rechnung.

**Online nutzen:** [Minecraft Server RAM-Rechner](https://ventrohosting.com/tools/minecraft-ram-rechner) · Demo: https://dannytheone.github.io/minecraft-ram-calculator/

## Funktionen

- RAM-Bedarf nach gleichzeitigen Spielern, Serverart (Vanilla/Paper, Plugins, Mods) und Weltgröße
- Nachvollziehbare Faustformel mit Startwert und Reserve
- Läuft komplett im Browser, ohne Anmeldung

## English

Minecraft server RAM calculator: estimate how much memory your server needs from concurrent players, server type (vanilla/Paper, plugins, mods) and world size. Runs entirely in the browser.

Use it online: https://ventrohosting.com/tools/minecraft-ram-rechner

## Selbst hosten

Statische Seite ohne Build-Schritt und ohne Abhängigkeiten: `index.html` und `tools.js` auf einen beliebigen Webserver legen oder GitHub Pages aktivieren. Alles läuft im Browser, es werden keine Daten gesendet.
